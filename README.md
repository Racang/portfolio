# Rachaya's Portfolio

A personal portfolio website showcasing my UX/UI design work and projects.

## 🎨 Design & Development

This portfolio was designed by me as a UX/UI designer using **Figma**, and the code was generated with the assistance of **AI** to bring the design to life.

To streamline the development process, I configured AI to retrieve Figma design context and details using **Figma DevMode MCP server**, enabling seamless translation from design to code.
